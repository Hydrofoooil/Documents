# 分析维度库 v4.0

## 使用指引

**选取原则：** 优先覆盖论文主图（Figure 1/2）所展示的核心 pipeline 中的关键模块。若论文创新横跨多个维度，可选取更多；若创新高度集中，3 个维度即可。每个维度下的分析深度应与论文叙述的篇幅匹配。

**维度间关系提示（防止混淆）：**
- **Multi-modal Encoding** 与 **Tactile & Force Sensing**、**3D Scene Representation** 有交集：前者侧重多模态整体编码架构，后两者侧重特定模态的深度技术分析。若论文的核心贡献在于某一特定模态的深入创新（如触觉预训练、3DGS 场景编辑），应选后者而非前者。
- **Policy Architecture** 与 **Imitation Learning** 互补：前者聚焦网络结构本身（Diffusion / Flow Matching / Transformer），后者聚焦学习范式与示教数据。
- **Hierarchical Control** 与 **Embodied Reasoning** 和 **Compositional Skill Assembly**（Planning 维度内）的区分：Hierarchical Control 指固定的层级架构设计；Embodied Reasoning 指动态的推理过程；Compositional Skill Assembly 指技能的代数组合。
- **Scaling Laws & Cross-Embodiment** 与 **Data Engine** 互补：前者关注宏观规律与跨形态泛化，后者关注数据工程的具体实现。
- **Locomotion** 和 **Manipulation** 侧重物理建模与领域特定控制策略，与 **Policy Architecture**（通用策略架构）互补使用，分析时通常需要同时选取。

## 维度库

| 维度名称 | 适用场景 | 关注要点 |
|---|---|---|
| **Multi-modal Perception & Encoding** | 涉及视觉/语言/触觉/点云等**多模态**输入的论文 | 各模态的 encoder 选型、tokenization 方式、预训练策略 |
| **Cross-modal Fusion & Alignment** | 多模态信息需要交互对齐的论文 | 融合机制（cross-attn / early-late fusion / contrastive）、对齐损失 |
| **3D Scene Representation & Spatial Reasoning** | 使用 NeRF / 3DGS / 点云 / 体素 / SDF 等显式或隐式三维表征的论文 | 场景表征类型（3DGS vs NeRF vs voxel vs SDF）、是否可编辑/可微分渲染、空间推理机制（affordance prediction / spatial grounding）、与策略学习的耦合方式 |
| **Tactile & Force Sensing** | 以触觉传感器为核心输入或研究触觉表征学习的论文 | 触觉传感器类型（GelSight / BioTac / 电子皮肤）、触觉信号的编码与预训练、视觉-触觉融合策略、力控与接触力估计 |
| **Representation & State Abstraction** | 核心贡献在于**单模态或低维状态**的表征学习（区别于多模态编码） | 潜空间学习（VAE / VQ / contrastive）、proprioceptive embedding、state abstraction for RL、表征质量的评估方式 |
| **World Model / Dynamics Learning** | World Model、Model-Based RL、视频预测类论文 | 潜空间设计、dynamics model 架构、imagination / rollout 机制（open-loop vs closed-loop）、prediction loss、与 MPC / planning 的集成方式 |
| **Policy Architecture & Decision-Making** | 所有涉及策略网络的论文 | 策略表征（MLP / Transformer / Diffusion / Flow Matching / VQ）、决策层设计 |
| **Action Representation & Decoding** | VLA、操作类论文 | 动作空间定义（连续/离散/混合）、action chunking、解码方式（autoregressive / diffusion）；action tokenization 层级（language description → code → affordance → trajectory → goal state → raw action） |
| **Imitation Learning & Demonstration** | 以模仿学习为核心方法的论文（BC / DAgger / IRL 等），或聚焦于示教数据采集方式的论文 | 示教方式（遥操作 / 人体视频 / VR / 运动捕捉）、数据增强策略（viewpoint augmentation / 3DGS-based generation）、行为克隆变体（ACT / Diffusion Policy / Flow Matching Policy）、covariate shift 应对 |
| **Reward Design & Shaping** | RL 类论文 | 奖励函数设计（sparse / dense / shaped / learned / LLM-generated）、reward hacking 防范、reward learning（IRL / RLHF / preference-based） |
| **Exploration, Sample Efficiency & Offline RL** | RL / 离线 RL / Online RL 类论文 | 探索策略、数据利用效率、off-policy vs on-policy；offline RL 特有问题：distributional shift、conservative estimation（CQL / IQL / TD3+BC 等）、offline-to-online fine-tuning 策略 |
| **Locomotion & Contact Dynamics** | Humanoid / 四足 / Loco-Manipulation 类论文。侧重物理建模与领域特定控制策略，与 Policy Architecture 互补使用 | 步态生成、接触建模、质心动力学、全身控制(Whole-body Control)、物理一致性 |
| **Manipulation & Grasp Strategy** | Dexterous / Mobile Manipulation 类论文。侧重物理建模与领域特定控制策略，与 Policy Architecture 互补使用 | 抓取策略、手指协调、力/阻抗控制、任务与运动规划(TAMP) |
| **Hierarchical / Modular Control** | 分层架构（High-level + Low-level）的论文 | 层级间通信接口、子目标空间定义、各层频率设定、模块化程度 |
| **Planning & Reasoning** | 涉及长 horizon 任务规划的论文 | 任务分解、子目标生成、搜索/规划算法（MCTS / CEM / LLM planning）、closed-loop replanning；compositional skill assembly（技能的代数组合，如 LoRA composition / parameter-space blending）；long-horizon skill chaining 中的 error accumulation 与 recovery |
| **Embodied Reasoning & Chain-of-Thought** | 在策略执行中引入显式推理链的论文（ECoT / CoT-VLA / Inner Monologue 等） | 推理链形式（语言 / 子目标图像 / code）、推理与实时控制的时序交织方式（System 1 vs System 2 架构）、reasoning trace 的监督来源、对可解释性的影响 |
| **Sim-to-Real & Real-to-Sim Transfer** | 涉及仿真与真实环境迁移的论文 | Domain Randomization、System ID、teacher-student distillation、仿真器选型；real-to-sim 逆向迁移、automatic curriculum in sim |
| **Data Engine, Benchmark & Evaluation** | 数据收集/生成/增强方法类论文，或以提出 Benchmark 为核心贡献的论文 | 数据来源与规模、自动化标注/筛选、数据质量与多样性；数据飞轮（closed-loop autonomous data collection → training → deployment → new data）；benchmark 设计（任务覆盖度、评估指标设计、baseline 选取合理性）；跨 benchmark 统一评估框架（Embodied Arena / EmbodiedBench） |
| **Foundation Model Adaptation** | 将 LLM/VLM 适配到机器人任务的论文 | 微调策略（LoRA / full-FT / prompt-tuning）、embodiment grounding 方法；in-context learning for robotics、VLM as reward/critic/verifier、LLM-based code generation for control |
| **Scaling Laws & Cross-Embodiment Transfer** | 研究模型/数据规模效应，或跨机器人形态泛化的论文 | 数据量-性能 scaling 关系（power law 拟合）、数据多样性 vs 数量的权衡、跨 embodiment 的统一动作空间设计、morphology-agnostic 表征、模型尺寸与能力的相变点 |
| **Test-Time Compute & Adaptive Inference** | 在推理阶段动态调整计算量或进行在线适应的论文 | 推理预算分配策略（difficulty-aware / confidence-based）、diffusion step 动态调整、test-time training / adaptation、inference 延迟与成功率的 trade-off |
| **Safety, Robustness & Generalization** | 强调鲁棒性与泛化的论文 | 分布外泛化、对抗扰动、安全约束（CBF / constrained RL）、failure recovery；formal verification of learned policies（对神经网络策略的数学性质证明）、safe flow matching / CBF-constrained policy generation |
| **System & Hardware Co-design** | 涉及硬件/系统层面创新的论文 | 传感器配置、执行器设计、计算架构、实时性约束；edge inference 与模型压缩（量化 / 蒸馏 / pruning for on-robot deployment）、能耗约束 |
| **Memory & Temporal Modeling** | 涉及长时序记忆、时间抽象、技能发现的论文 | 外部记忆模块（episodic memory / retrieval-augmented）、temporal abstraction（option framework / skill discovery）、context window 处理策略、history encoding 架构 |
| **Multi-Agent & Collaboration** | 多机器人协作、群体智能类论文 | 通信机制（显式/隐式）、任务分配策略、集中式 vs 去中心化训练与执行、协作操作中的角色分工 |
